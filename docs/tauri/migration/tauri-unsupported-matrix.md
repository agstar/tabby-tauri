# Tauri Unsupported / Provider Migration Matrix

This matrix is the source of truth for Tauri runtime APIs that are still
unsupported, intentionally unavailable, or being migrated to Rust/Tauri
providers. New runtime `unsupported(...)` call sites must be added here with a
test and an explicit disposition before they are accepted.

Status taxonomy: `graph-excluded`, `explicitly-unsupported`,
`hidden-by-capability`, `provider-in-progress`, `provider-backed`,
`deleted-shim` (legacy shim namespace removed; any remaining unsupported
surface must be a named guard, not a fake Node/Electron runtime).

| API / Feature | Runtime surface | Disposition | User-visible handling | Verification |
|---|---|---|---|---|
| `PlatformService.exec(app, argv)` | `tabby-tauri/src/index.ts` | Implement allowlisted Rust provider only | Known WinSCP callsites are routed through `exec_allowlisted`; the WSL mixer subprocess probe was removed; arbitrary commands reject | provider tests assert command exists and arbitrary exec is not exposed |
| `HostAppService.exec(app, argv)` | `tabby-tauri/src/index.ts` | Implement allowlisted Rust provider only | Shares `exec_allowlisted` with platform service | same as platform exec |
| `PlatformService.openPath(path)` | `tabby-tauri/src/index.ts` | Implement allowlisted Rust provider | The WSL volume mixer opens through `open_path_allowlisted('sndvol.exe')`; directories and non-executable absolute files are allowed for user-visible file/folder open paths; executable/script paths reject | provider tests assert `sndvol.exe` and safe paths are allowed while executable/script paths reject |
| `HostAppService.newWindow()` | `tabby-tauri/src/index.ts` | Implement via Tauri `WebviewWindow` | Fire-and-forget sync API opens another Tauri window | source and capability tests cover `WebviewWindow` and `tabby-*` capability |
| Auto-update | `tabby-tauri/src/index.ts` | Hide/disable until a real updater provider is chosen | Tauri updater reports `isAvailable = false`; settings and update badge do not call it | UI/source tests guard `updater.isAvailable` |
| UAC elevation | `tabby-tauri/src/index.ts` | Hide/disable until an elevation provider is implemented | `isAvailable = false`; existing local profile context checks hide it | existing UAC optional checks stay intact |
| Opacity | `tabby-tauri/src/index.ts` | Hide while Tauri opacity API is unavailable | `displayCapabilities.opacity.supported = false` | settings template gates on `platform.displayCapabilities.opacity.supported` |
| Monitor enumeration | `tabby-tauri/src/index.ts` | Product decision / future provider | No monitor-dependent UI should appear without a provider | docking remains absent unless provider source-of-truth agrees |
| Docking | runtime provider absent; stale helper references removed | Hide until monitor + window placement provider exists | Optional `DockingService` absence hides docking settings | tests assert no stale `UnsupportedDockingService` helper/provider drift |
| SSH `keyboardInteractive` | `tabby-tauri/src/index.ts`, `tauri-app/src-tauri/src/ssh.rs` | Provider-backed renderer prompt channel | Tauri emits shared keyboard-interactive prompt panels and waits for renderer responses | mapping, renderer, and Rust request tests |
| SSH jump/proxy/agent/X11 forwarding gaps | `tabby-tauri/src/index.ts`, `tauri-app/src-tauri/src/ssh.rs` | Future Rust SSH provider per feature | Hidden/disabled by Tauri SSH capability gates and rejected before authentication if stale configs request them; local TCP, dynamic SOCKS, and remote forwarding are provider-backed | unsupported feature list and UI/source/Rust tests |
| Sync `fs` guard | `app/src/tauri-guards/fs.ts`; `app/src/tauri-providers/fs-promises.ts` | Intentionally unsupported for sync calls; async path is Rust-provider-backed | Use async `fs/promises` or a dedicated provider | guard/provider tests assert explicit sync rejection and Rust command invocation |
| Node `http`/`https` | `app/src/tauri-guards/http.ts`, `https.ts` | Intentionally unsupported unless concrete callsite requires provider | Prefer browser `fetch` or scoped Rust command | guard tests assert explicit rejection |
| Node `tls` | `app/src/tauri-guards/tls.ts` | Intentionally unsupported unless concrete callsite requires provider | No fake TLS context | guard tests assert explicit rejection |
| `net.createServer` | `app/src/tauri-providers/net.ts` | Product decision / future Rust listener | TCP client is provider-backed; server stays explicit unsupported | provider tests assert TCP client Rust commands and explicit server rejection |
| Dynamic SOCKS forwarding | `app/src/tauri-guards/socksv5.ts`; `tauri-app/src-tauri/src/ssh.rs` | Provider-backed for SSH profile dynamic forwarding; generic `socksv5` package calls remain an explicit guard | SSH dynamic forwarding uses Rust-owned SOCKS5 listener over russh `direct-tcpip`; generic Node SOCKS package calls still reject explicitly | Rust SOCKS roundtrip tests; source tests assert the alias and generic guard exist |
| Electron `russh` APIs | `app/src/tauri-guards/russh.ts` | Intentionally unsupported guard | Tauri SSH must use `TauriSshConnection`/Rust backend | tests assert Tauri sessions do not use Electron backend |
| Disabled Node builtins | `app/webpack.config.tauri.mjs` | Intentionally disabled until scoped provider exists | Avoids fake Node runtime in WebView | `check:no-electron` and bundle tests |
